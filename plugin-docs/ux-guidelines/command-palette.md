# 命令面板

[命令面板](/api/references/contribution-points#contributes.commands)是所有命令的集中位置。为了让用户能够轻松找到命令，正确标记命令名称非常重要。

**✔️ 应该**

* 在适当的地方添加键盘快捷键
* 为命令使用清晰的名称
* 将命令按相同类别分组

❌ 不应该

* 覆盖现有的键盘快捷键
* 在命令名称中使用表情符号
