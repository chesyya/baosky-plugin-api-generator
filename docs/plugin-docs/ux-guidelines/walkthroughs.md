# 入门指引 (Walkthroughs)

入门指引通过包含丰富内容的多步清单，为引导用户使用插件提供了一致的体验。

**✔️ 建议**

- 使用有用的图像为当前入门指引步骤添加上下文。
- 确保图像在不同颜色主题下都能工作。如果可能，使用带有 Baosky [主题颜色](/api/references/theme-color) 的 SVG。[Baosky Color Mapper](https://www.figma.com/community/plugin/1218260433851630449) Figma 插件可以轻松实现 SVG 的主题化。
- 为每个步骤提供操作（例如，查看所有命令）。尽可能使用动词。

**❌ 不建议**

- 在单个入门指引中添加过多数量的步骤。
- 除非绝对必要，否则添加多个入门指引。
