# 快速选择 (Quick Picks)

[快速选择](/api/extension-capabilities/common-capabilities#quick-pick) 是一种执行操作和从用户接收输入的简单方法。这在选择配置选项、需要过滤内容或从项目列表中挑选时很有帮助。

<!-- 图片已移除 -->

**✔️ 建议**

* 使用图标表达清晰的隐喻。
* 使用经过深思熟虑的图标，增加清晰度并帮助区分项目。
* 使用描述显示当前项目（如果适用）。
* 使用详细信息提供（简短的）附加上下文。
* 对一系列基本输入使用多步模式。
* 在从列表中挑选时提供创建新项目的选项（如果适用）。
* 为多步快速选择使用标题。
* 为没有文本输入的快速选择使用标题。
* 为要求文本输入的快速选择使用标题（使用占位符显示提示或示例）。
* 为具有全局按钮（例如刷新图标）的快速选择使用标题。

**❌ 不建议**

* 重复现有功能。
* 当占位符本身可以描述目的时使用标题。
* 使用没有占位符的输入。

## 多步

快速选择可以配置为具有多个步骤。当您需要在单个流程中捕获相关但独立的选择时，请使用这些。避免对具有许多步骤的长流程使用快速选择——它们不太适合充当向导或类似复杂的体验。

<!-- 图片已移除 -->

*注意快速选择标题中的“1/3”文本，它指示流程中的当前步骤数和总步骤数。*

## 多选

对需要在一个步骤中选择的密切相关的选择使用多选快速选择。

<!-- 图片已移除 -->

## 标题

快速选择也可以配置为在主输入和选择 UI 之上显示标题栏。当用户需要更多上下文来进行选择时使用标题。避免使用已经用于快速选择输入占位符的标签作为标题。

<!-- 图片已移除 -->

## 使用分隔符

快速选择项目可以使用快速选择分隔符分组到清晰的部分中。这些具有分隔线和标签以清楚地显示该部分。如果插件具有包含多个明显选择组的快速选择，请使用分隔符。
